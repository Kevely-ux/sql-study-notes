06

Filme / Personagem

Entregue 06/09

Views, agregações e a técnica de "achar quem não está em outra tabela sem usar a coluna óbvia no filtro".

TabelaColunas
filmeid, titulo, tipo, diretor, ano_lancamento
personagemid, nome, especie, nivel_importancia, id_filme
  1. Criar as tabelas filme e personagem
  2. Inserir pelo menos 3 filmes e 10 personagens
  3. Buscar o nome do filme e a quantidade de personagens
  4. Buscar o nome do diretor e a quantidade de filmes dirigidos por ele
  5. Buscar o nome, espécie e nível de importância de todos os personagens ordenando a lista pelo ano de lançamento do filme que participam e por ordem do mais importante para o menos importante
  6. Buscar o título do filme e o nome dos personagens que o filme é de ação ou drama
  7. Mostrar em uma única coluna o nome do diretor e dos personagens ordenado por ordem alfabética
  8. Criar uma view chamada "view_filme" com as informações: título e tipo
  9. Buscar na "view_filme" todas as informações ordenadas pelo título do filme
  10. Criar uma view chamada "view_personagem" com as informações: nome, espécie e id do filme
  11. Utilizando a "view_personagem" buscar o nome do personagem e o título do filme
  12. Criar uma view chamada "view_filme_personagem" com as informações: título do filme, tipo, diretor, ano de lançamento e nome do personagem de todos os filmes que o ano de lançamento é par
  13. Buscar o título de todos os filmes que o ano de lançamento não é par. Não pode utilizar no filtro da busca a coluna "ano_lancamento"
  14. Buscar o título do filme, tipo, diretor, ano de lançamento e nome do personagem que não estão na "view_filme_personagem"
Ver gabarito

Convenção: nivel_importancia — 1 é o mais importante, números maiores = menos importante. Dados de exemplo: 5 filmes conhecidos (Matrix, Toy Story, Titanic, Pantera Negra, Interestelar), com anos par e ímpar misturados de propósito pra testar os itens 12-14.

CREATE TABLE filme (
    id INT AUTO_INCREMENT,
    titulo VARCHAR(100),
    tipo VARCHAR(100),
    diretor VARCHAR(100),
    ano_lancamento INT,
    PRIMARY KEY(id)
);

CREATE TABLE personagem (
    id INT AUTO_INCREMENT,
    nome VARCHAR(100),
    especie VARCHAR(100),
    nivel_importancia INT,
    id_filme INT,
    PRIMARY KEY(id),
    FOREIGN KEY(id_filme) REFERENCES filme(id)
);

3 — Filme e quantidade de personagens
SELECT f.titulo, COUNT(p.id) AS qtd_personagens
FROM filme f
JOIN personagem p ON p.id_filme = f.id
GROUP BY f.id, f.titulo;
4 — Diretor e quantidade de filmes
SELECT diretor, COUNT(*) AS qtd_filmes
FROM filme
GROUP BY diretor;
5 — Ordenado por ano do filme e importância
SELECT p.nome, p.especie, p.nivel_importancia
FROM personagem p
JOIN filme f ON f.id = p.id_filme
ORDER BY f.ano_lancamento ASC, p.nivel_importancia ASC;
6 — Filmes de ação ou drama
SELECT f.titulo, p.nome
FROM filme f
JOIN personagem p ON p.id_filme = f.id
WHERE f.tipo IN ('Ação', 'Drama');
7 — Diretor + personagens numa coluna só
SELECT diretor AS nome FROM filme
UNION
SELECT nome FROM personagem
ORDER BY nome;
8-9 — view_filme
CREATE VIEW view_filme AS
SELECT titulo, tipo FROM filme;

SELECT * FROM view_filme ORDER BY titulo;
10-11 — view_personagem
CREATE VIEW view_personagem AS
SELECT nome, especie, id_filme FROM personagem;

SELECT vp.nome, f.titulo
FROM view_personagem vp
JOIN filme f ON f.id = vp.id_filme;
12 — view_filme_personagem (só ano par)
CREATE VIEW view_filme_personagem AS
SELECT f.titulo, f.tipo, f.diretor, f.ano_lancamento, p.nome AS nome_personagem
FROM filme f
JOIN personagem p ON p.id_filme = f.id
WHERE f.ano_lancamento % 2 = 0;
13 — Filmes de ano ímpar, sem usar ano_lancamento no filtro
SELECT DISTINCT f.titulo
FROM filme f
WHERE NOT EXISTS (
    SELECT 1 FROM view_filme_personagem vfp WHERE vfp.titulo = f.titulo
);
14 — O que não está na view_filme_personagem
SELECT f.titulo, f.tipo, f.diretor, f.ano_lancamento, p.nome AS nome_personagem
FROM filme f
JOIN personagem p ON p.id_filme = f.id
WHERE NOT EXISTS (
    SELECT 1 FROM view_filme_personagem vfp
    WHERE vfp.titulo = f.titulo AND vfp.nome_personagem = p.nome
);
07

Animal / Animal Feroz

Entrega 13/09

Triggers de BEFORE/AFTER pras três operações (INSERT, UPDATE, DELETE) e duas functions.

TabelaColunas
animalid, especie, nivel_feroz, herbivoro_carnivoro
animal_ferozid, especie, herbivoro_carnivoro, registros
  1. Criar as tabelas animal e animal_feroz
  2. Criar um trigger para antes de inserir um animal verificar se o nível_feroz está entre 1 e 5. Se sim ok, senão exibir mensagem erro
  3. Criar um trigger para depois de inserir um animal verificar se o nível_feroz for 4 ou 5 deve cadastrar esse animal na tabela animal_feroz e atribuir 1 para registros
  4. Criar 6 animais (5 com sucesso e 1 com nivel_feroz inválido)
  5. Criar um trigger para antes de atualizar um animal verificar se está mudando a espécie. Se sim, não deixar atualizar
  6. Atualizar um animal e mudar a espécie dele para "espécie inválida"
  7. Criar um trigger para depois de atualizar um animal incrementar o valor de registros daquele animal se for feroz
  8. Atualizar 1 animal feroz e atualizar 1 animal que não é feroz
  9. Criar um trigger para antes de deletar um animal verificar se é herbívoro e não permitir
  10. Apagar um animal herbívoro
  11. Criar um trigger para depois de deletar um animal apagar ele da tabela animal_feroz
  12. Apagar um animal que o nivel_feroz é 4 ou 5
  13. Criar uma função que recebe como parâmetro a espécie do animal e retorna "Animal feroz!" ou "Animal não é muito feroz!" dependendo se ele existe ou não na tabela animal_feroz
  14. Buscar todas as informações de todos os animais e também chamar a função para falar se é ou não feroz
  15. Criar uma função que recebe como parâmetro a letra inicial de herbívoro ou carnívoro e retorna o texto "Herbívoro" ou "Carnívoro" conforme a entrada
  16. Buscar a espécie e chamar a função que fala se é Herbívoro ou Carnívoro
Ver gabarito

As duas tabelas não têm FOREIGN KEY entre si (não apareceu no diagrama da aula) — a ligação entre animal e animal_feroz é feita "na mão" pelos triggers, casando pelo nome da especie.

1 — Tabelas
CREATE TABLE animal (
    id INT AUTO_INCREMENT,
    especie VARCHAR(100),
    nivel_feroz INT,
    herbivoro_carnivoro VARCHAR(1),
    PRIMARY KEY(id)
);

CREATE TABLE animal_feroz (
    id INT AUTO_INCREMENT,
    especie VARCHAR(100),
    herbivoro_carnivoro VARCHAR(1),
    registros INT,
    PRIMARY KEY(id)
);
2 — BEFORE INSERT: validar nível_feroz (1 a 5)
DELIMITER $$
CREATE TRIGGER trigger_before_insert_animal
BEFORE INSERT ON animal
FOR EACH ROW
BEGIN
    IF NEW.nivel_feroz < 1 OR NEW.nivel_feroz > 5 THEN
        SIGNAL SQLSTATE '45000'
        SET MESSAGE_TEXT = 'Nível de ferocidade deve estar entre 1 e 5';
    END IF;
END $$
DELIMITER ;
3 — AFTER INSERT: cadastrar em animal_feroz se nível 4 ou 5
DELIMITER $$
CREATE TRIGGER trigger_after_insert_animal
AFTER INSERT ON animal
FOR EACH ROW
BEGIN
    IF NEW.nivel_feroz IN (4,5) THEN
        INSERT INTO animal_feroz(especie, herbivoro_carnivoro, registros)
        VALUES (NEW.especie, NEW.herbivoro_carnivoro, 1);
    END IF;
END $$
DELIMITER ;

INSERT INTO animal(especie, nivel_feroz, herbivoro_carnivoro) VALUES ('Leão', 5, 'C');
INSERT INTO animal(especie, nivel_feroz, herbivoro_carnivoro) VALUES ('Coelho', 1, 'H');
INSERT INTO animal(especie, nivel_feroz, herbivoro_carnivoro) VALUES ('Lobo', 4, 'C');
INSERT INTO animal(especie, nivel_feroz, herbivoro_carnivoro) VALUES ('Cervo', 2, 'H');

INSERT INTO animal(especie, nivel_feroz, herbivoro_carnivoro) VALUES ('Hamster', 8, 'H');
-- Error Code: 1644. Nível de ferocidade deve estar entre 1 e 5
5 — BEFORE UPDATE: bloquear mudança de espécie
DELIMITER $$
CREATE TRIGGER trigger_before_update_animal
BEFORE UPDATE ON animal
FOR EACH ROW
BEGIN
    IF OLD.especie <> NEW.especie THEN
        SIGNAL SQLSTATE '45000'
        SET MESSAGE_TEXT = 'Não é permitido alterar a espécie do animal';
    END IF;
END $$
DELIMITER ;
6 — Tentar mudar espécie (deve falhar)
UPDATE animal SET especie = 'Espécie inválida' WHERE especie = 'Leão';
-- Error Code: 1644. Não é permitido alterar a espécie do animal
7 — AFTER UPDATE: incrementar registros se for feroz
DELIMITER $$
CREATE TRIGGER trigger_after_update_animal
AFTER UPDATE ON animal
FOR EACH ROW
BEGIN
    IF NEW.nivel_feroz IN (4,5) THEN
        UPDATE animal_feroz
        SET registros = registros + 1
        WHERE especie = NEW.especie;
    END IF;
END $$
DELIMITER ;
8 — Atualizar 1 feroz e 1 não feroz
UPDATE animal SET nivel_feroz = 5 WHERE especie = 'Lobo';    -- feroz, incrementa registros
UPDATE animal SET nivel_feroz = 2 WHERE especie = 'Coelho';  -- não feroz, não mexe em animal_feroz
9 — BEFORE DELETE: bloquear se for herbívoro
DELIMITER $$
CREATE TRIGGER trigger_before_delete_animal
BEFORE DELETE ON animal
FOR EACH ROW
BEGIN
    IF OLD.herbivoro_carnivoro = 'H' THEN
        SIGNAL SQLSTATE '45000'
        SET MESSAGE_TEXT = 'Não é permitido apagar um animal herbívoro';
    END IF;
END $$
DELIMITER ;
10 — Apagar um herbívoro (deve falhar)
DELETE FROM animal WHERE especie = 'Cervo';
-- Error Code: 1644. Não é permitido apagar um animal herbívoro
11 — AFTER DELETE: apagar da animal_feroz também
DELIMITER $$
CREATE TRIGGER trigger_after_delete_animal
AFTER DELETE ON animal
FOR EACH ROW
BEGIN
    DELETE FROM animal_feroz WHERE especie = OLD.especie;
END $$
DELIMITER ;
12 — Apagar um carnívoro feroz (nível 4 ou 5)
DELETE FROM animal WHERE especie = 'Crocodilo';
-- permitido (é carnívoro) — e o AFTER DELETE já remove ele de animal_feroz
13 — Function: é feroz ou não?
DELIMITER $$
CREATE FUNCTION verificar_animal_feroz(p_especie VARCHAR(100))
RETURNS VARCHAR(100)
DETERMINISTIC
BEGIN
    DECLARE qtd INT;
    DECLARE resultado VARCHAR(100);
    SET qtd = (SELECT COUNT(*) FROM animal_feroz WHERE especie = p_especie);
    IF qtd > 0 THEN
        SET resultado = 'Animal feroz!';
    ELSE
        SET resultado = 'Animal não é muito feroz!';
    END IF;
    RETURN resultado;
END $$
DELIMITER ;
14 — Todos os animais + classificação
SELECT *, verificar_animal_feroz(especie) AS classificacao
FROM animal;
15 — Function: traduzir H/C
DELIMITER $$
CREATE FUNCTION traduzir_tipo_animal(letra VARCHAR(1))
RETURNS VARCHAR(20)
DETERMINISTIC
BEGIN
    DECLARE resultado VARCHAR(20);
    IF letra = 'H' THEN
        SET resultado = 'Herbívoro';
    ELSEIF letra = 'C' THEN
        SET resultado = 'Carnívoro';
    ELSE
        SET resultado = 'Desconhecido';
    END IF;
    RETURN resultado;
END $$
DELIMITER ;
16 — Espécie + tipo traduzido
SELECT especie, traduzir_tipo_animal(herbivoro_carnivoro) AS tipo
FROM animal;
